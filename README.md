# AWS OpenSearch Mini Project

A Java-based AWS project demonstrating AWS services with Amazon OpenSearch.

## 🏗️ Architecture

![AWS OpenSearch Project Overview](./AWS%20OpenSearch%20Project%20Overview.png)

## 🚀 Technologies Used

- Java
- AWS Lambda
- Amazon DynamoDB
- Amazon OpenSearch
- Amazon S3
- AWS SDK for Java
- Gradle

## 🔄 Project Flow

Java Application → AWS Lambda → DynamoDB → OpenSearch → Search & Analytics
